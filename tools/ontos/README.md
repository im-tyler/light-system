# ontos_stream_dump

Third independent implementation of the ontos stream spec (normative: ontos repo, `docs/STREAM_SPEC.md`) — Rust sim (ontos), Python verifier (simval), this C++17 std-only re-simulator. Verifies both format versions: v1 life (Phase 0) and v2 gravity (Phase 2: leapfrog + Chebyshev ephemeris windows + momentum ledger, re-simulated bit-exactly with bounded drift reported against an all-fine reference; section 19 Phase 4 collapse/expand: RegionCollapsed totals, monopole gravity, jitter + residual-velocity synthesis; section 20 Phase 4 v2 multipole reconstruction: RegionMultipole dipole/quadrupole totals, dipole-exact position residual + Cholesky quadrupole transform on expansion — streams without RegionMultipole records reconstruct per section 19; section 23 Phase 4 v3 radial-shape synthesis: RegionRadial binding totals, binding-matched radial scale (pinned bisection) + spread-scale kinetic-energy closure on expansion; section 21 contact dynamics: Contact records (tag 10), sticky contact mode, the pinned single-pass impulsive resolution re-simulated bit-exactly with post-impulse closure reported; section 24 contact extensions: ContactParams (tag 12) restitution/friction/walls, one-sided static impulses against ephemeris-coarse bodies, collapsed-region monopoles (pseudo body ids), and bounded-world walls — all ledger-booked like fc kicks; section 22 modal audio: contact-excited damped resonators resynthesized bit-exactly, with the section 24 pseudo-id reduced-mass rule — FNV-1a64 hash over the PCM printed on the OK line, WAV render via `--wav`). Spike toward the ontos Phase 3 viewer bridge: JoltViewer thin-consumer pattern, zero coupling to the renderer core.

Build: `clang++ -std=c++17 -O2 -ffp-contract=off -o ontos_stream_dump ontos_stream_dump.cpp`

`-ffp-contract=off` is required: the spec bans FMA (determinism section), and clang contracts `a*b+c` into FMA by default at -O2, which breaks bit-exactness on the first tick.

Usage: `./ontos_stream_dump <stream-file> <seed> [--wav out.wav]` (example streams + seeds: simval `examples/ontos*/`)

Exit codes: 0 = all records verified · 1 = verification mismatch (first bad record printed) · 2 = bad stream (magic/version/world size/truncation/unknown tag) · 3 = usage, I/O, or FNV self-check failure.
